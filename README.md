# ⚖️ ClipDiff Linux - Instant Visual Side-by-Side Diff Viewer

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Linux%20(X11%20%26%20GNOME)-orange.svg)]()
[![Python](https://img.shields.io/badge/Python-3.8%2B-green.svg)]()

A fast, lightweight, visual side-by-side text and code difference viewer for Linux. Highlight Text A, hit **`Alt + 1`**, highlight Text B, hit **`Alt + 2`**, and instantly view a clean, color-coded side-by-side diff window!

---

## ✨ Features

- ⚡ **2-Step Magic Shortcut (`Alt + 1` ➔ `Alt + 2`):**
  - Highlight any original snippet / text ➔ Press `Alt + 1` (captured).
  - Highlight modified snippet / text ➔ Press `Alt + 2` (opens instant diff modal).
- 🎨 **Sleek Visual Diffing:** Color-coded additions (green) and deletions (red) in side-by-side view.
- 💻 **CLI Support:** `clipdiff file1.txt file2.txt`.

---

## 🛠️ Installation

```bash
git clone https://github.com/domz-1/clipdiff.git
cd clipdiff
make install
```
